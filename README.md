# 麦克团队 - 直播公会内部管理小程序

直播公会内部管理工具，提供音浪打卡、排班管理、请假审批、数据看板等功能。

## 功能模块

| 模块 | 说明 |
|------|------|
| 登录/注册 | 微信快捷登录、新用户注册（需管理员审核） |
| 首页 | 音浪统计、日常通道快捷入口、昨日排行榜 |
| 音浪打卡 | 每日音浪数提交打卡 |
| 数据看板 | 多时间段数据筛选、优秀主播排行、个人数据 |
| 直播间排班 | 周视图排班表、排班申请 |
| 请假 | 请假申请与审批记录 |
| 音浪任务 | 月度任务进度与每日明细 |
| 公告通知 | 公会公告查看 |
| 我的 | 个人数据总览、功能菜单 |

## 快速开始

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开微信开发者工具，选择「导入项目」
3. 项目目录选择本文件夹
4. AppID 可使用测试号或填入自己的 AppID
5. 点击「编译」即可预览

## 项目结构

```
├── app.js / app.json / app.wxss   # 全局配置
├── pages/
│   ├── landing/       # 登录页
│   ├── register/      # 注册页
│   ├── index/         # 首页
│   ├── checkin/       # 音浪打卡
│   ├── dashboard/     # 数据看板
│   ├── schedule/      # 直播间排班
│   ├── profile/       # 我的
│   ├── leave/         # 请假
│   ├── task/          # 音浪任务
│   └── notice/        # 公告通知
├── utils/mock.js      # 模拟数据
└── assets/icons/      # TabBar 图标
```

## 技术说明

- 基于微信小程序原生框架开发
- 当前使用本地模拟数据，接入后端时替换 `utils/mock.js` 中的数据接口即可
- 登录状态通过 `wx.setStorageSync` 本地持久化
